Storage rules

How persistence works

Each uploaded resume becomes a local structured profile that you can select for analysis. The extracted source text stays local for exact evidence quotes; no original file is uploaded or retained by the extension. Match history is scoped to the selected resume profile and each job record expires after 30 days.
